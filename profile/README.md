## 🧠 Overview

Adobe Bridge is the file browser that ships with Creative Cloud: it previews and organises assets across folders and drives, reads and writes metadata, batch-renames files and hands raw images to Camera Raw without opening a full editor. It is developed by Adobe. The product family is positioned as a digital asset browser toolset for Windows workflows.

Adobe Bridge works as a desktop application on Windows 10 and Windows 11 and is installed alongside a host application such as Adobe Creative Cloud applications.

## 🚀 Key Features

| Feature | Description |
| --- | --- |
| 🗂️ Asset Browsing | Previews images, video, PDFs and InDesign files in a single grid or list view. |
| 🏷️ Metadata Editing | Reads and writes EXIF, IPTC and XMP fields across a whole selection. |
| 🔎 Filtered Search | Filters by keyword, camera, lens, rating, colour label and date. |
| ✏️ Batch Rename | Renames files with patterns, sequence numbers and metadata tokens. |
| 🖼️ Camera Raw Access | Opens raw files in Camera Raw and saves the settings back to the file. |
| 📤 Output Workspace | Builds PDF contact sheets and web galleries from a selection. |
| 🏷️ Collections | Saved searches and smart collections group assets without moving files. |

## 💻 System Requirements

| Component | Minimum / Recommended |
| --- | --- |
| Operating System | Windows 10 64-bit (version 21H2 or newer) or Windows 11 |
| Processor | 64-bit Intel or AMD processor with SSE4.2 support |
| Memory | 8 GB RAM minimum, 16 GB recommended for large raw folders |
| Graphics | GPU with 2 GB VRAM, driver from 2022 or newer |
| Display | 1280 x 800 or higher |
| Storage | 4 GB free disk space for the application and its cache |

## Additional Information for Windows Users

Package details: maintained by Adobe.
